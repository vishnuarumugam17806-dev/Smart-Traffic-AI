# Alert Engine Specification

The Alert Engine manages real-time system alarms and watchlist triggers.

---

## 1. Alert Types & Severity

Alarms are generated for the following conditions:
- **`BLACKLISTED_VEHICLE`** (CRITICAL): A plate listed on the watch registry is sighted.
- **`ROUTE_ANOMALY`** (HIGH): Sighting speeds exceed physical thresholds.
- **`EMERGENCY_VEHICLE`** (HIGH): Sirens/ambulances preempt signal sequences.
- **`ACCIDENT` / `WRONG_WAY`** (HIGH): Blockages or traffic violations detected.
- **`CAMERA_OFFLINE` / `SYSTEM_ERROR`** (MEDIUM): Telemetry connection drops.

---

## 2. Alarm Lifecycle & Resolution Workflow

Active alarms follow a structured status transition state:
```
[ NEW ] ──(Acknowledge)──> [ ACKNOWLEDGED ] ──(Resolve)──> [ RESOLVED ]
```
- **NEW**: Alarm generated by CV/background task. Pushed to WebSocket client.
- **ACKNOWLEDGED**: Operator marks alarm as noted. Rerouting rules apply.
- **RESOLVED**: Alarm closed. History logged in audit records.
